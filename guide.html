使用教程

适合 v1.0.6.x Windows / macOS / Linux

基本操作

装好之后，桌宠默认出现在屏幕右下角并播放待机动画，系统托盘同时出现常驻图标。

操作效果
左键点击桌宠触发点击互动动画（会播放点击音效）
按住并拖动移动桌宠；松开后按方向与速度处理转向、移动或惯性
按住 SHIFT + 左键拖动开启「SHIFT+左键拖动」后，这是唯一的拖动方式
右键桌宠打开带图标的上下文菜单（可切换新旧菜单模板）
光标停在鱼身上按鼠标侧键（前进）打开 / 收起宠物养护卡片
双击托盘图标显示 / 隐藏桌宠
右键托盘图标设置、AI 对话、开机自启、退出等菜单
桌宠隐藏后动画与全部定时器会暂停，CPU 占用接近 0%，显示时立即恢复。

拖动与不透明度

在「桌宠设置 → 桌宠行为 → 拖拽」与「外观 → 桌宠显示」中调整：

  • 锁定位置：开启后桌宠固定不动，点击互动仍然有效。
  • SHIFT+左键拖动：开启后必须按住 SHIFT 才能拖动，适合防止误拖。
  • 不透明度：10%–100% 可调，数值越小越透明，保存立即生效。
以上三者与「鼠标穿透」不同：穿透后桌宠完全不接收鼠标事件，需要从托盘或右键菜单关闭。

播放速率与动作间隔

调整播放速率

  1. 右键桌宠（或托盘菜单）→「桌宠设置」。
  2. 调整「播放速率」，范围 1.0x 到 2.0x。
  3. 保存后当前与后续片段都会按新速率播放。

设置动作等待间隔

「动作等待间隔」默认是 0。设为大于 0 时，相邻的非待机、非转向动画之间会等待指定秒数，等待期间仍允许待机和转向动画播放，用于降低连续动作的密集节奏。

开启自言自语气泡

  1. 在「桌宠设置」中勾选「开启自言自语气泡」。
  2. 设置「随机间隔最短」和「随机间隔最长」。
  3. 在「自言自语内容」中每行填写一条文本，留空则恢复内置内容。

气泡默认显示在角色可见形象的正上方并水平居中；上方空间不足时会自动选择不遮挡角色的位置。

开机自启

  1. 右键系统托盘图标。
  2. 勾选菜单中的「开机自启」。
  3. 取消勾选即关闭。状态直接读写当前用户的注册表 Run 键（Windows）或登录项 / autostart（macOS / Linux），无需管理员权限。
若自启不生效，多为安全软件清理了未签名程序的自启项，请到其「启动项管理」中恢复；程序每次启动会自检并在被清理时气泡提醒。

直播捕获兼容模式（Windows）

用哔哩哔哩直播姬 / OBS 做窗口捕获时如果找不到桌宠，是因为它默认是"工具窗口"形态（不占任务栏，捕获软件会过滤）。

解决办法：在「桌宠设置」中勾选 「直播捕获兼容模式」，保存后桌宠会变为普通顶层窗口并显示标题，即可在窗口捕获列表里选中；代价是任务栏会出现桌宠图标，不开直播时取消勾选即可。

切换与热加载角色

右键菜单中的角色选择入口每次打开都会重新扫描角色目录，无需重启即可切换；Chat 版会同步更新角色名称、头像、主题色与会话隔离。

热加载新角色：文件怎么放

桌宠会自动扫描外部角色目录，目录名即角色 ID，含 webm 或 gif 即被识别：

characters/
└── mycat/                    ← 目录名 = 菜单里显示的角色 ID
    ├── manifest.json         ← 可选：角色名 / prompt / 主题色 / 动作映射
    └── videos/
        ├── idle/  turn/  move/  click/  drag/  random/

两个扫描位置（exe 同目录优先，其次用户数据目录，后者跨升级保留）：

平台exe 同目录用户数据目录
Windows<安装目录>\characters\%APPDATA%\dsh-pet\data\dsh-pet-standalone\characters\
macOS.app/Contents/MacOS/characters/~/Library/Application Support/dsh-pet/data/...
Linux源码运行目录 characters/~/.config/dsh-pet/data/...
