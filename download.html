Install

安装教程

方式一：安装包（setup.exe）

下载并双击运行

出现 SmartScreen 提示时点「更多信息 → 仍要运行」（软件尚未购买代码签名证书）。

选择语言与目录

默认简中；默认装到 %LOCALAPPDATA%\Programs\...，也可浏览选到别的盘符。

可选创建快捷方式

勾选「创建桌面快捷方式」，完成后点「运行」立即启动。

方式二：绿色版（zip）

解压到任意可写目录

例如 E:\dsh-pet\，保持文件夹内结构完整。

双击同名 exe

例如 dsh-pet-standalone-webm-chat.exe 即可运行。

删除即卸载

整个文件夹删掉即可，不残留运行缓存。

macOS 使用

  1. 下载并解压得到 .app，可拖入「应用程序」文件夹。
  2. 首次打开：右键 .app →「打开」；或终端执行 xattr -dr com.apple.quarantine xxx.app。
  3. 数据目录：~/Library/Application Support/dsh-pet/data/。

Linux 使用

unzip dsh-pet-standalone-webm-chat-linux-x86_64.zip
cd dsh-pet-standalone-webm-chat
./dsh-pet-standalone-webm-chat

首次运行若缺库（Debian/Ubuntu 系）：

sudo apt install libxcb-cursor0 libxkbcommon-x11-0 libegl1 libgl1 \
                 libfontconfig1 libdbus-1-3 fonts-noto-cjk

卸载与升级

  • 卸载（安装版）：设置 → 应用 → 已安装的应用 → 找到 dsh-pet-standalone → 卸载。配置与会话默认保留。
  • 升级（安装版）：直接运行新版 setup.exe 覆盖安装，配置与聊天记录不受影响。
  • 升级（绿色版）：用新版 zip 覆盖旧文件夹即可。
