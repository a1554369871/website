常见问题

找不到桌宠了

看系统托盘（可能收在「显示隐藏的图标」里），双击托盘图标可显示 / 隐藏桌宠。如果开了「鼠标穿透」，需要从托盘或右键菜单关闭它才能重新点到桌宠。

开机自启不生效

常见原因是安全软件 / 系统优化工具（360、电脑管家、Defender 等）拦截或清理了未签名程序的自启项。

  • 到安全软件的「开机加速 / 启动项管理」中恢复桌宠自启项。
  • 程序每次启动会自检：若发现「之前开启过但已被清理」，桌宠会气泡提醒。
  • macOS 新版系统需在「系统设置 → 通用 → 登录项」中允许桌宠（勾选时也有气泡提示）。

数据存在哪里

自 v1.0.8.0 起，设置与聊天会话默认保存在安装目录下的数据根里，不再固定写在 C 盘；首次启动会自动把旧 %APPDATA%\dsh-pet\data 数据复制过来。安装版 / 绿色版（Windows）：

运行方式数据目录
Chat 版<安装目录>\data\dsh-pet-standalone-webm-chat\
无 Chat 版<安装目录>\data\dsh-pet-standalone-webm\
源码运行%APPDATA%\dsh-pet\data\dsh-pet-standalone\
macOS~/Library/Application Support/dsh-pet/data/
Linux~/.config/dsh-pet/data/

可用环境变量 DSH_PET_DATA_ROOT 自定义数据根。常见文件：config.json（设置与位置）、pet_journal.json（宠物日记）、pet_diary_chat.json（和它唠嗑）、会话 JSON 等。

卸载与升级

  • 卸载（安装版）：设置 → 应用 → 已安装的应用 → 找到 dsh-pet-standalone → 卸载。卸载会清除全部用户数据（配置、会话、宠物日记、缓存与 API Key），如需保留请先备份。
  • 升级（安装版）：运行新版 setup.exe 覆盖安装，配置与聊天记录不受影响。
  • 绿色版：解压覆盖旧文件夹即可；删除文件夹即卸载。

直播捕获找不到窗口

桌宠默认是「工具窗口」形态，会被 OBS / 直播姬的窗口捕获过滤掉。在「桌宠设置」中勾选 「直播捕获兼容模式」 即可被捕获；代价是任务栏会出现桌宠图标。

隐私与安全

  • 发布物不含任何本地运行数据、聊天历史与私人凭据（仓库 data/ 仅保留占位文件）。
  • 「看看屏幕」与「主动识屏」的截图仅在内存中处理并直接发送给你配置的模型服务商，不写入本地文件，也不发送到本项目自建服务器。
  • API Key 优先使用系统钥匙串存储，钥匙串不可用时可按设置选择配置文件回退。
  • 请你遵循所配置模型服务商的隐私政策。

macOS / Linux 注意

  • macOS：未签名（ad-hoc），首次需右键 →「打开」或去除隔离属性；官方仅提供 Apple Silicon 包。
  • Linux：建议 X11 桌面；缺库时安装 libxcb-cursor0 libxkbcommon-x11-0 libegl1 libgl1 libfontconfig1 libdbus-1-3 fonts-noto-cjk；GNOME 托盘需装 AppIndicator 扩展。
