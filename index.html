Features

它不只会卖萌

从桌面陪伴到宠物养成，再到 AI 对话，一条鱼全包了。

🪟

透明无边框

置顶、可拖动、拖动带惯性，隐藏后动画与定时器全部暂停，几乎不占 CPU。

🎬

高清动画

内置 91 段透明 WebM 动画，待机、点击、移动、随机动作分层调度，播放速率可调。

💬

AI 对话（Chat 版）

兼容 OpenAI 接口，默认接入 DeepSeek；流式输出、多轮上下文，每个角色一条连续对话。

🍲

宠物养护

心情 / 饱食双状态，14 道菜谱、做菜投喂、冰箱保鲜、菜市场买食材，摸鱼还能赚小鱼干。

📖

宠物日记

每天 23:00 用第一人称写一条日记，记录当天发生了什么事和它的小心情。

🗣️

和它唠嗑

它会自己起话题、你没回会追问；日常说的话都记进唠嗑线程，你也能直接回它。

⏰

久坐提醒

连续在用电脑太久，它会在头顶冒泡劝你起身，点一下还能领小鱼干奖励。

👀

主动识屏陪伴

Windows + Chat 版可选：白名单应用切换时，用人设口吻冒泡关怀，截图不落盘。

🐳

DeepSeek 余额

一键查询开放平台账户余额，气泡显示，还可开启自动刷新与点击查看。

Quick Start

三步就能养上

下载并安装

下载 setup.exe 双击安装（免管理员），或解压绿色版 zip 后双击 exe。

桌宠出现在桌面

默认在屏幕右下角播放待机动画，系统托盘出现常驻图标；左键点击互动，按住拖动移动。

按需配置

右键桌宠打开菜单，进入「桌宠设置」调整外观与行为；Chat 版再填一个 DeepSeek API Key 就能聊天。
