AI 对话教程

零基础快速配置 创建 API Key 高级设置 看看屏幕 DeepSeek 余额 常见报错
仅 Chat 版 兼容 OpenAI 接口

零基础快速配置（照抄版）

不想研究 API 的话，打开「AI 设置」后只需要填一样东西：API Key，其他按下面照抄即可。

设置项填这个
API 地址https://api.deepseek.com
模型deepseek-v4-flash
API Key在 DeepSeek 开放平台创建（步骤见下）
软件首次打开时，API 地址和模型默认就是上面这两个值，不用改，粘上 Key 就能用。

创建 API Key

打开开放平台

访问 platform.deepseek.com，用手机号注册 / 登录。

进入 API Keys

左侧菜单找到「API Keys」→「创建 API Key」。

复制密钥

复制生成的 sk- 开头密钥（只完整显示一次，务必立刻保存）。

填入桌宠

右键桌宠 →「AI 设置」→ 粘贴到 API Key → 保存。

测试连接

点「测试连接」，看到「连接成功」就可以去聊天了。

高级设置

  • 支持 OpenAI Chat Completions 兼容接口；可自定义 API 地址、模型、超时、温度和最大输出 token。
  • 支持 SSE 流式输出、多轮上下文裁剪、会话 JSON 持久化、停止生成、失败重试。
  • 对话按角色隔离，切换角色不会把旧角色消息带过去。
  • API Key 优先使用系统钥匙串；不可用时可按设置选择配置文件回退。
  • 聊天窗支持内置主题壁纸 / 自定义图片 / 裁剪取景 / 桌面透明，遮罩浓度可调。
系统提示词（System Prompt）在「设置 → AI 设置」里配置，它同时决定普通聊天和宠物日记、和它唠嗑的人设。

看看屏幕（Chat 版）

右键菜单 →「看看屏幕」：截取当前屏幕（含多显示器）→ 附带前台窗口「程序名 | 标题」→ 发给视觉模型，用人设口吻回应一句，结果以气泡显示。

  • 回复会自动同步到 AI 对话当前会话，可继续追问；聊天窗未打开时仅气泡显示。
  • 截图自动压缩（最长边 768px、JPEG 70）后仅在内存中处理，不写入本地文件。
  • 视觉模型可在 AI 设置中单独配置，或勾选「同聊天模型」复用聊天配置。
每次「看看屏幕」都会按一次视觉模型请求计费；有 4 秒冷却防连点，免费档高峰可能遇到限流。

DeepSeek 余额

右键菜单或托盘 →「DeepSeek 余额」：查询开放平台账户余额，以气泡显示，例如「余额 ¥12.34（充值 ¥10.00 / 赠送 ¥2.34）」。

  • 数据来自 DeepSeek 官方 /user/balance 接口，使用当前配置的 API Key 鉴权（需使用官方端点）。
  • 结果 30 秒内缓存复用，重复查询秒回。
  • 设置里可开启「余额自动刷新」（分钟级，0=关闭）与「点击显示余额」。

常见报错

提示原因与处理
认证失败（401/403）Key 复制漏了字符或多了空格，重新粘贴一次。
余额不足（402）账号没额度了，网络和配置正常，去平台充值即可。
连接超时检查网络 / 代理，或适当调大「超时」设置。
限流（高峰）免费档高峰可能限流，稍后重试。
