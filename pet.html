认识状态：心情与饱食

大肥鱼有 饱食度 和 心情 两个状态。把鼠标停在它身上按鼠标侧键（前进键），或右键菜单「宠物养护」、托盘菜单，都能打开跟随桌宠的养护卡片。

  • 饱食度默认每 3 小时现实时间下降 20%，心情随时间缓慢下降，饿太久时心情掉得更快。
  • 关掉软件期间照常衰减，但只有约四成速度，并且有保底（饱食不低于 35、心情不低于 40），不会饿死。
  • 卡片顶部两栏并排读数：状态词比数字大，先告诉你「有点饿了」，数字供核对；跌破 30 会转成灶红色。
改系统时间没有意义：时间往回拨会被忽略，往未来跳最多按 7 天结算，离谱的时间戳会被拉回当下。

摸鱼赚小鱼干

点一下大肥鱼 = 摸一下，加心情也赚 1 条小鱼干；在线挂机每小时再捡 2 条。

  • 摸鱼收益用令牌桶限速：每小时回 20 条、最多攒 8 条，连点约 8 下后变慢，但不会像每日硬上限那样一锁到半夜。
  • 额度用光时它会冒一句「被我摸太多啦…N 分钟后再给我一下下」。
  • 卡片标题行的 🐟 数量旁实时显示下一条什么时候到（「+1 就绪」/「+1 2分」，最后一分钟按秒数）。
  • 心情越高单次加得越少（80 以上 +1，95 以上只 +0.2），心情每天最多涨 200 点。

菜市场与菜谱

用小鱼干在「菜市场」买食材，价格就是那一行的主角，买不起会标红。常见价格：大米 6、面条 8、鲜肉 14、鱼虾 18、砂糖 4、火锅底料 22（🐟）。

「菜谱」页列出每道菜需要什么食材、多久、回多少饱食和心情。食材齐的菜左边会亮蛋黄色边并写着「食材齐了」，点「选材」一键把食材丢进锅并跳回「做菜」。

内置 14 道菜：白米饭、早餐套餐、午餐便当、手工饺子、腊八粥、清蒸大闸蟹、团圆火锅……全部复用已有进食动画。

做菜与投喂

  1. 下锅：锅有四个固定锅位（空位是虚线格子），点下面的食材丢进锅，点锅里的食材可取回。
  2. 凑菜：搭配必须和某道菜完全一致才算凑成，整口锅左缘转蛋黄并提示收益、解锁「开做」；只放一半会提示还差什么。
  3. 开做：占用一个灶眼（共 3 个），要等真实时间，做好了自动进冰箱。
  4. 投喂：冰箱里点「投喂」，播放对应吃饭动画并涨饱食 / 心情。太饱（>90）硬喂收益减半还倒贴心情，撑到 98 直接拒绝。
投喂从 v1.0.6.4 起改为动画结束后才结算；动画期间再次投喂会被婉拒（「嘴里还嚼着呢」）。

冰箱保鲜

做好的菜先存冰箱，12 格、24 小时保鲜，每格有一条新鲜度带，快不新鲜的标红并写「先喂这个」，超过 24 小时会被清掉。

离线期间冰箱里的菜同样会过期，所以按节奏做、按顿喂最划算，而不是一次囤一周。

它也会照顾自己

饿极了它会自己动手：先翻冰箱吃现成的，没有就自己煮碗白米饭，实在没食材还会自己掏小鱼干去买菜。可以在设置里关掉「饿了会自己煮」。

你不在的时候，冰箱就是它的食堂。

久坐提醒

默认连续在用电脑 45 分钟，它就在头顶冒泡劝你起身，气泡下面挂着两个可点的小标签：「我起身了」 和 「等会儿」。

  • 键鼠空闲超过 5 分钟算你休息过，计时清零，回来重新坐满一整个周期才会再提醒。
  • 点「我起身了」会重置计时、记进日记，并奖励心情 +2、你 +6 条小鱼干；点「等会儿」只是往后推一轮。
  • 心情越低提醒越勤：很差时约 0.6 倍（45 → 27 分钟），很好时放宽到 1.3 倍（→ 58.5 分钟）。
  • macOS / Linux 拿不到键鼠空闲数据，退化为固定节奏提醒。

宠物日记

它会记下你对它做了什么，也记下它自己干了什么：被摸、被拖动、投喂、做菜出锅、看看屏幕、查余额、生小肥鱼……

  • 日记用大肥鱼第一人称口吻写成，2–4 句、不超过 200 字，允许自由发挥但不编造没发生的事。
  • 每天只写一次：事实先免费记在本地，到本地时间 23:00 合并成一条；应用没运行则下次启动补写一条。
  • 没配 API Key 或调用失败时自动改用本地文案，绝不会把「HTTP 401」写进日记。
  • 保留最近 200 条，存放在配置目录的 pet_journal.json。
无 Chat 版本看不到日记界面，但事件仍会正常记进本地文件。

和它唠嗑

聊天窗左侧栏「宠物日记」下面有固定入口「和它唠嗑」，记录大肥鱼平时说的话，你也可以直接回它，入口与普通对话相互独立、不可删除。

  • 它会主动起话题：大概每 60–180 分钟（可调）没在聊时自己找话头，头顶也会冒一句。
  • 收录所有发言：自言自语、吃喝养护、久坐提醒、主动识屏、agent 联动、查余额、看看屏幕以及状态气泡都会记进唠嗑线程（宠物日记除外）。
  • 你没回它会追问：默认 10 分钟没回会再问一句（只追问一次）；下次起话题还会先问「上次怎么没理我」。
  • 话题双方都能收尾；数据存在 pet_diary_chat.json。
