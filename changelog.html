Changelog

更新日志

当前维护的权威版本线为 1.0.x。以下按时间倒序排列。

v1.0.7.0

便携数据根 + 卸载清除全部数据

  • 新增便携数据根：用户数据默认跟随安装目录（<安装目录>\data\），不再固定写在 C 盘 %APPDATA%。
  • 首次启动会把旧 %APPDATA%\dsh-pet\data 数据自动复制到新位置（只复制不删除）。
  • 数据根支持重定向：环境变量 DSH_PET_DATA_ROOT、exe 同目录 marker、全局指针依次覆盖；DSH 桥接插件同步适配。
  • 卸载清除全部用户数据：配置、会话、宠物日记、缓存、DSH 桥接事件与系统钥匙串中的 API Key。
  • 新增 Windows 下载器：可选版本与安装盘符、可预填 AI 配置，一步下载安装。
v1.0.6.7

唠嗑全量收录 + 日记每日成文

  • 大型唠嗑线程收录大肥鱼的所有发言：自言自语、吃喝养护、久坐提醒、主动识屏、agent 联动、查余额、看看屏幕及状态气泡（宠物日记除外）。
  • 随机自言自语只展示、不作为模型回复的上下文，避免它对着自己的碎碎念接话。
  • 宠物日记改为每天本地 23:00 写一条；应用没运行则下次启动补写一条。
v1.0.6.6

点击排队修复

  • 同时勾选「点击显示余额」与「点击随机自言自语」时，按承诺自动排队：先余额气泡，结束后隔约 1 秒再播自言自语。
  • 连续点击会重置序列，只按最后一次点击从头完整显示，不叠加气泡。
v1.0.6.5

聊天背景完善

  • 「裁剪取景」真正生效：按归一化取景框先裁后缩放，现代与经典聊天窗都适用。
  • 新增「桌面透明」背景，遮罩浓度从完全透明到纯黑可调，覆盖侧边栏与标题栏。
  • 现代聊天窗标题栏新增外观设置快捷入口。
v1.0.6.4

投喂改为动画结束后结算

  • 喂食时先扣菜并播放动画，动画播完才加饱食度 / 心情；动画期间再次投喂会被婉拒。
  • 「和它唠嗑」默认滚到最新消息，并复用 System Prompt 人设。
v1.0.6.3

会话管理去重

  • 内置 AI 对话窗移除重复的会话管理（新建、列表、搜索、重命名、置顶、批量、删除等），交给 DSH 页面本身。
  • 侧栏只留「宠物日记」「和它唠嗑」两个原生页与「跟随桌宠」，每个角色保持一条连续对话。
v1.0.6.2 / v1.0.6.1 / v1.0.6

启动优化系列

  • 修复 DSH 联动「一键安装桥接插件」在 corepack pnpm、中文 Windows、源码开发版 home 等场景下的失败。
  • AI 设置新增「DeepSeek Harness 桌面版路径」，「启动 DeepSeek Harness」优先打开桌面版客户端，找不到再回退网页版。
v1.0.5

陪伴版：和它唠嗑

  • 新增「和它唠嗑」：记录大肥鱼日常说的话，你可以回复，它会主动起话题、你没回会追问一次。
  • 宠物日记改为两步生成（先思考再写正文），措辞更拟人。
v1.0.4 / v1.0.3 / v1.0.2

数据治理与宠物养护

  • 所有用户数据统一收纳到单一数据根 %APPDATA%\dsh-pet\data，首次启动自动迁移旧目录。
  • 重做宠物养护卡片；新增宠物养护体系（心情 / 饱食、做菜投喂、宠物日记、久坐提醒）。
v4.0.x（上游主线）

桌面体验与性能基线

  • 现代双 UI：新版右键菜单、设置对话框、AI 对话窗口（侧栏 + 卡片 / 双栏工作台）。
  • 隐藏即零功耗、启动懒加载、主动识屏陪伴、Agent 联动。
  • 锁定位置、SHIFT 拖动、不透明度、托盘菜单同步等桌宠新功能。

完整历史请查看 GitHub Release 页面。
